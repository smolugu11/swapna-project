Run the .py file with pytest .\test_math_func.py
-Pytest does not require you to manually call your test functions like test_add() or test_sub(). Instead, it automatically discovers and runs any function that
Pytest will:
- Scan your project for files like test_math_func.py
- Find all functions that start with test_
- Run them automatically
- Report which tests passed or failed

*py.test -> it will auto discover all the test files and run the tests inside them and give you a summary of the results.
*py.test -v -> gives you a more verbose output, showing each test function name and its result (pass/fail).
*py.test -k "expression"(funch  name without test "add" which gonna run test with add keywords only)" -> allows you to run tests that match a specific expression
*Py-test -rA -> gives all the info about the tests c
*py test test name -> can only run metioned tests
*pytest -rA -fE(failed)
** all the report can be saved into xml with pytest -rA --junitxml="report1.xml" - whenever you need cuostmer report you can generate your own report.
** default report generated by pytest : pip install pytest-html, pytest --rA --html=myreport.html
